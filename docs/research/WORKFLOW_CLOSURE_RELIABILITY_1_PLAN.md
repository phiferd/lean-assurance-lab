# Make closure reliable and measure intervention cost

Status: READY and unstarted; selected after exploration-protocol adoption.

**What did we find?** Resource closure exposed concurrent state edits and
receipt-discovery interactions. E0 now has a lightweight route; full confirmation
closure still needs repair. Token records exist, but an exact whole-item cost
baseline has not been established by this implementation.
**Is it interesting?** Yes. Fixing those mechanisms benefits future confirmatory
semantic work and makes claimed efficiency improvements measurable.
**Does it require more work?** Reproduce the known failure classes in focused
fixtures, repair the smallest shared control surface, and measure interventions.
No new scientific matrix or historical memory audit is authorized by selection.

## Scoped work

Establish one closure owner and stable validation inputs. Separate generated
control receipts from scientific discovery. Reuse a completed validation stage
only when all declared dependencies and tool identities are unchanged; otherwise
invalidate it. Preserve raw failures automatically and fail closed on unknown
invalidations. Start with existing controls, not a new general-purpose scheduler.
Collect local token records by unique response identity, keep cached/uncached
input and output separate, record missing coverage, and avoid inferring dollars.
Keep private conversation contents out of the repository; retain aggregate
accounting and reproducible extraction logic only.

## Completion and boundaries

Show concurrency prevention, safe interruption/resume, changed-dependency
invalidation, and receipt isolation in regression tests, then one real ordered
closure with no intermediate model decisions on its successful mechanical path.
Run affected and full current/historical validation for the shared change and
refresh existing derived views. Report measured cost and unknowns; do not infer
savings from passing tests alone. Preserve frozen evidence/tooling and milestone
gates, use explicit successors when needed, and make no external writes except
authorized main delivery. At entry bind the exact implementation scope before
editing; at closure compare a concrete E0 semantic-diversity campaign with the
remaining memory audit and select without starting it. No automatic expensive
agent fan-out is needed for this item.
