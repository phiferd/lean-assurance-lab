# Historical-fault transfer screen

Evidence class: E0

## Question and value

Do the Lab's fixed compact, non-Collatz inputs distinguish affected and fixed
implementations for two real historical validation faults: official Lean's
nested-unused-parameter behavior and Nanoda's projection-structure identity
behavior? This asks whether general retained cases transfer to known faults
without including their disclosed or generated Collatz witnesses.

The result can show an existing transferable protection, a specific corpus
blind spot, or an input-compatibility boundary. It does not estimate defect
prevalence, compare implementation quality, or reopen the frozen Collatz
retrospective.

## Fixed scope and entry gate

Use the exact affected/fixed binaries and SHA-256 identities already bound in
`results/collatz-retrospective/freeze.json`:

- official Lean 4.29 versus official Lean 4.33;
- Nanoda `ddfac2b` versus Nanoda `6ae1f0c`.

Before launch, verify all four executable bytes and select the same complete
90-file compact corpus frozen by `E0-TEST-EFFECTIVENESS-CAMPAIGN-1`. Exclude
every file under `corpus/collatz-retrospective`, the disclosed Arena holdout,
and the prior targeted congruence pair. Preserve the exact selection, commands,
configuration, raw outcomes and supervision receipts. Record one prospective
start per historical fault before observing either affected/fixed pair.

Use the existing process supervisor with 30 seconds, 2 GiB sampled RSS, a
3-second sampling target and 10-second cleanup. An input must parse and reach a
comparable observation on both revisions before it can support a transfer
claim. Keep acceptance, rejection, parser or adapter failure, timeout and
cleanup outcomes distinct. Repair ordinary runner defects within the same
trial and retain every attempt.

## Completion and limits

Complete both 90-input affected/fixed comparisons or preserve an exact
compatibility or capability boundary. A differing verdict is an E0 transfer
signal, not fresh discovery of the historical bug or proof that the input
isolates the same cause. Source or diagnostic review is required before any
causal attribution. Equal outcomes mean only that this fixed sample showed no
transfer signal.

No builds, source edits, generated candidates, Box/FnAlias work, assurance
refresh, external contribution or upstream communication are authorized. Close
through the ordinary E0 ledger and campaign handoff, then select an unstarted
successor.
