# Small contributor tasks — local review drafts

Choose one question and expected artifact, then agree scope and ownership with
the maintainer. These cards are unpublished proposals, not selected campaigns
or a promise that setup works on every machine. No Zulip post is included here.

| Task | Best fit | First artifact |
| --- | --- | --- |
| [Draft-to-append CLI round trip](python-cli-draft-roundtrip.md) | Python/testing | One meaningful CLI integration test in a disposable synthetic repository |
| [Rejection with a formatting panic](retained-diagnostic-fixture.md) | Python/testing | Retained diagnostic fixture and supervisor-failure control regression |
| [Preserved-alias eta seam](lean-alias-source-review.md) | Lean/kernel expert | Pinned source map, duplicate check and four-case prospective matrix |

The first two use repository files and Python development dependencies; they
need no large corpus or Lean checker build. The third begins source-only and
stops at a normalization, duplicate or runner-capability boundary. A negative
finding or concrete boundary is a valid useful contribution. Scientific execution
requires separate queue selection and its entry gates. Shared code still receives
the applicable full validation; lightweight E0 is not an exemption for a fix.

Follow [the first-contribution path](../../CONTRIBUTING.md#your-first-small-contribution).
The full survivor investigation and issue12 corpus requirements remain a separate
advanced task. Repeated contributions can continue from one accepted small artifact
after the maintainer and contributor agree on the next question; there is no new
community process or standing campaign in these drafts.
