## Maintenance contract

The JSON ledger is the canonical current index. Item-specific submission, evidence, and successor records remain authoritative for their detailed and historical claims.

- `scripts/build-external-contributions --write` validates the ledger and regenerates this view.
- `scripts/build-external-contributions --check` fails when the ledger is invalid or this view is stale.
- `scripts/refresh-current-state` regenerates this view as part of the ordinary offline state build.
- A GitHub observation must update the affected dated fields in the ledger; the build does not poll GitHub.
- New pull-request drafts use the `*-pr.md` filename suffix; validation rejects any such draft omitted from the ledger.
- Preparing, submitting, modifying, or following up on an external action still requires the repository's applicable human gate.
