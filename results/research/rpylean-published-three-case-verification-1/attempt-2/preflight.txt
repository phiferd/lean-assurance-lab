A type checker for the Lean theorem prover.

USAGE

  pypy -m rpylean <subcommand> [<args>]

OPTIONS

  --help: Show this help message
  --version: Show version information

COMMANDS

  check: Type check an exported Lean environment.
  dump: Dump an exported Lean environment or specific declarations from it.
  repl: Open a REPL with the given export's environment loaded into it.
  ffi: Talk to a real Lean toolchain via FFI.
