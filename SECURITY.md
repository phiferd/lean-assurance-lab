# Security Policy

Lean Assurance Lab may produce malformed proof artifacts or validator
disagreements with security implications. Do not publish details of a
previously undisclosed vulnerability in a public issue.

Use this repository's GitHub private vulnerability reporting channel. If that
channel is not available, contact the affected upstream project through its
security process before disclosing details here. Include exact revisions,
artifact hashes, reproduction commands, observed outcomes, impact, and any
known positive control.

Public, non-sensitive validator disagreements can use the validator-
disagreement issue form after coordinated disclosure is complete or the
affected maintainers confirm that public discussion is appropriate.

Reports are triaged as evidence, not decided by implementation count or
majority vote. An unadjudicated disagreement remains unresolved.
